# 720° 全景（盈悦华府 6栋 A1502）—— 自有可控版本

这是从原分享链接（`https://720.3vjia.com/S148917456`）一比一还原出来的**独立 720 全景**。
不依赖三维家服务器，素材全部在你本地，想改哪张图就改哪张图。

---

## 一、怎么看

双击 **`start.bat`** → 自动起本地服务器并打开浏览器（`http://localhost:8712/`）。
关掉黑色窗口即停止。

> 不要直接双击 `index.html`。浏览器对本地文件（file://）有限制，全景图会加载失败，必须走 `start.bat`。

**操作**：按住鼠标拖动 = 转视角；滚轮 = 缩放；点白色圆形箭头 = 走到那个房间；
底部一排缩略图 = 直接跳房间；右上「户型图」= 看平面图并点房间；「全屏」= 全屏；「自动旋转」= 缓慢自转。

**手机看**：手机和电脑连同一个 WiFi，把 `http://localhost:8712/` 换成
`http://你电脑的局域网IP:8712/`（如 `http://192.168.1.5:8712/`）。

## 二、怎么改图（重点）

每个空间的图片在 `panos/` 下，按房间分好文件夹：

```
panos/
  01-餐厅/      show_l.jpg show_f.jpg show_r.jpg show_b.jpg show_u.jpg show_d.jpg
  02-客卧/      同上
  03-书房/
  04-客厅/      ← 起始进入的房间
  05-主卫/
  06-过道/
  07-次卧/
  08-主卧/
  09-公卫/
  10-生活阳台/
```

**六面含义**（立方体贴图，每张 1500×1500）：

| 文件 | 朝向 |
|---|---|
| `show_f.jpg` | 正前方（进入该房间时看到的画面） |
| `show_r.jpg` | 右面墙 |
| `show_b.jpg` | 后面墙 |
| `show_l.jpg` | 左面墙 |
| `show_u.jpg` | 天花板 |
| `show_d.jpg` | 地面 |

**改图方法：用同名文件覆盖即可，不用改任何代码。**
PS 改完存成同样文件名（jpg）、同样 1500×1500，刷新页面就生效。

⚠️ 三个注意：
1. 六面是**互相拼接**的，改动跨到边缘时要让相邻两面接得上，否则会看到接缝。
2. 换图后浏览器有缓存，按 `Ctrl+F5` 强刷。
3. 图片别太小（建议保持 1500×1500），否则会变模糊。

## 三、改文字 / 改房间顺序 / 改门洞

全部集中在一个文件：**`scenes.json`**（用记事本或 VSCode 打开）。

- `"title"` → 顶部显示的标题
- `"startScene"` → 一进来先看哪个房间（填某个 `id`）
- `"scenes"` 里每个房间：
  - `"title"` → 缩略图和地图点显示的房间名
  - `"id"` → 唯一编号，**不要乱改**（热点靠它跳转）
  - `"lat"` / `"lng"` → 该房间在户型图上的位置（百分比，0~100）
  - `"hotspots"` → 门洞箭头：
    - `"ath"` 水平角：**0 = 正前方（f 面中心），数值增大 = 向右转**（0~360 / 负值亦可）
    - `"atv"` 垂直角：**正数 = 偏上，负数 = 偏下**（门洞一般 0~10）
    - `"next"` → 点了去哪个房间（填目标房间 `id`）

改完存盘，刷新页面生效。

## 四、放到网上（得到你自己的链接）

这套东西是**纯静态**的，任何静态托管都能放，不需要数据库/后端：

1. **自己的服务器 / 宝塔 / 阿里云 OSS / 腾讯云 COS**：把整个文件夹内容（`index.html` 所在目录）传上去即可，访问 `http://你的域名/` 就是 720 全景。
2. **GitHub Pages**：新建仓库 → 上传全部文件 → Settings → Pages → 选分支 → 得到 `https://用户名.github.io/仓库名/`。
   ⚠️ 单文件都 < 100MB，总 33MB，可以直接传。
3. 必须用 **http/https 打开**，不能直接双击本地文件。

想换 LOGO：替换 `assets/logo.png`；想换户型图：替换 `assets/map.png`。

## 五、目录说明

```
index.html          页面骨架
css/viewer.css      样式
js/viewer.js        查看器逻辑（拖拽/热点/切换/户型图）
js/three.min.js     3D 渲染引擎（Three.js，本地化，不联网）
scenes.json         全部场景数据（房间名/门洞/户型图点位）
panos/              10 个房间 × 6 面全景图（你要改的就是这里）
assets/             户型图、LOGO
tools/serve.py      本地预览服务器
tools/fetch.cjs     抓取脚本（万一要重新抓原站素材用）
tools/source.xml    原方案全景配置（krpano XML，房间/热点原始数据）
start.bat           一键本地预览
```
